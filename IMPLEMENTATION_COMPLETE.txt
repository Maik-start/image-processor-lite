🛠️ OPTIONS AVANCÉES
═══════════════════════════════════════════════════════════════════════════════

Compiler manuellement:
  cd imgprocessor/cpp
  python3 build_cpp.py

Compilation avec optimisations personnalisées:
  cd imgprocessor/cpp/build
  cmake .. -DCMAKE_CXX_FLAGS="-O3 -march=native -ffast-math"
  cmake --build . --config Release

Forcer le mode Python (debug):
  export IMGPROCESSOR_FORCE_PYTHON=1
  python test_optimizations.py
